# CodeStory

CodeStory 是一个面向非技术作者的作品可视化解读器。它从“作品能做什么”出发，将调用链逐段点亮，并支持从白话故事继续下钻到输入、处理、输出、关键函数、文件位置和失败路径。

## 当前演示项目

- Clipboard History：基于工作区 Swift 项目的真实代码结构整理。
- 小宇宙 AI 助手：基于产品行为预生成的演示映射。

所有演示数据均为本地静态数据，不上传代码、不调用外部模型。


```bash

```

## MVP 范围

- 两个预置作品及动作导览
- 点击动作后逐段高亮数据流
- 小白、产品、工程师三档旁白
- 节点级技术实现下钻
- 真实源码与预生成行为模型的证据标记
- 输入、处理、输出、依赖和失败路径
- 可折叠并记忆状态的作品导航
- 可拖动、键盘调宽和双击复位的技术详情面板
- 在技术详情中原位展开代码，保留文件位置、行号和复制能力
- 桌面与窄屏响应式布局

任意仓库解析、代码上传和实时 LLM 分析不在当前版本范围内。
