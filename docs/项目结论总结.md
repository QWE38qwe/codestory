# CodeStory 后端 MVP 结论

CodeStory 现已由纯前端 Demo 迁移为 `apps/web` 与 `apps/server` 的 npm workspace。已有 Story Player 与两个离线 Demo 保留；GitHub 仓库和本地项目通过统一的异步后端分析流程生成可播放 Story。

## 已交付

- Fastify + TypeScript 服务、Prisma + SQLite 数据模型、同源静态文件服务。
- GitHub 仓库读取与本地 multipart 上传；本地源码按 Job 写入临时工作区并在任务终态清理。
- AES-256-GCM 加密模型凭据、掩码展示、连接测试成功后替换和删除 API。
- 持久化单并发 Job Runner、进度查询、启动恢复和失败错误契约。
- 复用原有 digest、结构索引、Feature prompt、证据校验和 RuntimeProject adapter；自动选最多 3 个有真实文件证据的 Feature。
- Web API 客户端与 Job 轮询接入，API Key 不写浏览器存储；Player Demo 可离线使用。
- Server unit/API 测试、Web 导入流程测试、Playwright Demo 可用性检查及新的运行说明。

## 运行边界

支持 JavaScript、TypeScript、Python 源码，Markdown 与 JSON 可作上下文。GitHub 大仓库要求指定子目录；本地上传最多 400 个文件、单文件 200 KiB、总量 25 MiB。服务面向单用户本地或自托管单实例，不提供账号体系、多实例、Docker 或公网部署。

LLM Key 由用户输入，Server 测试通过后使用本机 `.env` 中的 32 字节 Base64 主密钥加密存入 SQLite。临时源码和数据库留在用户自托管环境；部署到可远程访问的主机时，需由运维方保护主机与 `.env`。
