# CodeStory 项目运行说明

## 1. 项目简介

CodeStory 是一个基于 React 和 React Flow 构建的代码作品可视化解读器。当前版本使用预置数据演示两个项目，通过动态调用链、分层旁白和代码证据，帮助非技术作者理解作品的运行过程。

项目可构建为纯静态站点。私有仓库能否使用 GitHub Pages 取决于 GitHub
账号与套餐权限，也可以将构建产物部署到其他静态托管服务。

## 2. 环境要求

建议使用以下环境：

- Node.js 20 或更高版本
- npm 10 或更高版本
- Chrome、Edge 或 Safari 等现代浏览器
- macOS、Windows、Linux 均可运行

本项目是纯前端静态应用，不需要数据库、后端服务、API Key 或 `.env` 环境变量。
演示数据随源码保存在 `src/data/` 中，运行时不会上传代码或请求外部模型。

检查本机环境：

```bash
node --version
npm --version
```

## 3. 获取项目

通过 Git 克隆：

```bash
git clone https://github.com/QWE38qwe/codestory.git
cd codestory
```

## 4. 安装依赖

仓库包含 `package-lock.json`，建议使用锁定版本安装：

```bash
npm ci
```

需要更新依赖或本地没有锁文件时，可改用：

```bash
npm install
```

## 5. 启动开发环境

执行：

```bash
npm run dev
```

终端会输出实际访问地址。默认地址为：

```text
http://127.0.0.1:5173/codestory/
```

如果 `5173` 已被占用，Vite 会自动尝试下一个可用端口，请以终端输出为准。
开发服务器支持热更新，修改 `src/` 下的文件后，浏览器会自动刷新。

停止服务时，在终端按 `Control + C`。

## 6. 首次体验建议

打开页面后，建议按以下顺序体验完整流程：

1. 在左侧作品导航中选择 `Clipboard History` 或“小宇宙 AI 助手”。
2. 选择一个用户动作，例如“记住一次复制”或“总结一期播客”。
3. 点击播放按钮，观察调用链按步骤逐段高亮。
4. 在“小白、产品、工程师”三档旁白之间切换，比较解释深度。
5. 点击任一流程节点，在右侧查看输入、处理、输出、依赖和失败路径。
6. 展开“完整代码”，核对文件位置、行号、证据类型并尝试复制代码。
7. 拖动右侧详情面板边缘调整宽度，双击分隔线可恢复默认宽度。

## 7. 构建生产版本

执行：

```bash
npm run build
```

构建结果会生成在 `dist/` 目录中。构建成功后，终端会显示 HTML、CSS 和 JavaScript 文件的体积。

## 8. 本地预览生产版本

先完成生产构建，然后执行：

```bash
npm run preview
```

根据终端输出访问 `/codestory/` 子路径。生产预览用于检查资源路径、页面交互和
构建结果，不建议将该命令直接作为长期线上服务。

## 9. 发布静态站点

项目已经配置 GitHub Pages 发布流程。确认当前 Git 用户具有仓库推送权限，且
GitHub 账号支持为私有仓库启用 Pages 后执行：

```bash
npm run deploy
```

该命令会自动：

1. 执行 `npm run build`。
2. 将 `dist/` 构建结果推送到 `gh-pages` 分支。
3. 更新线上页面。

GitHub Pages 可能需要几十秒完成缓存更新。若当前账号不支持私有仓库 Pages，
可将 `dist/` 目录部署到其他静态托管服务。

## 10. 主要目录

```text
codestory/
├── src/
│   ├── App.jsx                         # 页面结构与交互逻辑
│   ├── styles.css                      # 页面样式与响应式布局
│   ├── main.jsx                        # React 应用入口
│   └── data/
│       ├── projects.js                 # 项目、动作、节点和旁白数据
│       └── implementationDetails.js    # 技术实现、代码证据和代码块
├── docs/                               # 项目文档
├── index.html                          # HTML 入口
├── package-lock.json                   # npm 依赖锁文件
├── package.json                        # 依赖和运行命令
└── vite.config.js                      # Vite 与部署子路径配置
```

## 11. 运行数据与浏览器权限

- 项目和实现说明均为本地静态数据，不需要联网即可浏览。
- 左侧栏折叠状态和右侧详情面板宽度保存在浏览器 `localStorage` 中。
- “复制代码”功能需要浏览器剪贴板权限；若权限不可用，应用会尝试使用兼容方案。
- 清除该站点的浏览器数据即可重置已记忆的界面状态。

## 12. 常见问题

### 页面打开后是空白页

先确认依赖安装和构建是否成功：

```bash
npm ci
npm run build
```

然后查看浏览器控制台是否存在 JavaScript 或资源加载错误。

### GitHub Pages 上的资源返回 404

检查 `vite.config.js` 中的 `base` 是否与仓库名称一致：

```js
base: "/codestory/"
```

修改后重新运行：

```bash
npm run deploy
```

### 端口 5173 已被占用

Vite 会自动选择其他端口，也可以手动指定：

```bash
npm run dev -- --port 5178
```

访问地址相应变为：

```text
http://127.0.0.1:5178/codestory/
```

### 修改 Mock 数据

- 项目、动作、节点和旁白：修改 `src/data/projects.js`。
- 输入、处理、输出、函数和代码块：修改 `src/data/implementationDetails.js`。

修改后建议依次运行：

```bash
npm run build
npm run preview
```

确认无误后再发布。

## 13. 验证清单

提交或发布前建议执行：

```bash
npm ci
npm run build
npm run preview
```

在浏览器中确认：

1. 两个预置作品均能切换。
2. 动作播放、暂停、重置和步骤切换正常。
3. 小白、产品、工程师三档旁白可切换。
4. 技术详情、完整代码和证据标记可正常展开。
5. 左侧栏折叠、右侧面板调宽及窄屏布局正常。
