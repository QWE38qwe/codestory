# CodeStory 作品描述

CodeStory 是一款面向 Vibe Coding 创作者的代码作品可视化解读器，帮助作者理解一次操作背后的模块协作。它不从复杂文件树讲起，而是把作品整理成“记住一次复制”“总结一期播客”等用户动作。选择动作后，系统逐段点亮用户、界面、业务逻辑、存储与外部服务之间的调用路径，并提供“小白、产品、工程师”三档旁白，适配不同理解需求。

作品的核心亮点是从“白话故事”连续下钻到“技术证据”。点击节点即可查看职责、输入、处理、输出、关键函数、依赖、失败路径和代码位置，还能原位展开并复制完整代码。系统明确区分“真实源码”“系统行为”和“预生成行为模型”，避免把推演误当成代码事实。两个预置案例呈现本地存储、浏览器扩展、Native Host、系统钥匙串和 AI 服务的协作。

CodeStory 使用 React、React Flow、Fastify、Prisma 与 SQLite，支持调用链播放、步骤跳转、面板调节和响应式布局。两个预置 Demo 始终可以离线浏览；导入仓库时，后端会分析受支持的 GitHub 项目或短期上传的本地项目，自动选择最多三个具备真实代码证据的功能并生成 Story。用户提供的模型 Key 由 Server 加密保存在自托管环境，本地源码在 Job 结束后删除。其创新在于把“看不见的运行过程”转化为可播放、可追溯、可验证的作品故事，帮助创作者理解 AI 生成代码、定位模块边界与失败风险，并获得项目修改、排错、答辩和展示所需的掌控感。
